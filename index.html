SuperPlat Design System

PC와 모바일에서 동일하게 동작하고, Unreal Engine(UMG)에 그대로 이식 가능한 실무 디자인 시스템입니다. Toss Design System, Material Design 3, Apple HIG의 원칙을 기반으로 설계되었습니다.

Usage

Primary는 화면당 하나의 핵심 액션에만 사용합니다. Secondary와 동시에 과도하게 사용하면 시각적 위계가 무너집니다. Disabled 상태는 항상 명도 대비 3:1 이상을 유지해 "선택 불가"임을 인지할 수 있어야 합니다.

✓ Do

한 화면에 Primary Button은 최대 1개, 나머지는 Secondary로 위계를 구분합니다.

✕ Don't

Primary 색상을 배경이나 장식 요소에 남용해 정작 중요한 액션이 묻히게 하지 않습니다.

Code Example
/* SuperPlat — color tokens.css */ :root { --primary-500: #3182F6; --secondary-500: #64748B; --disabled-bg: #F1F3F5; --disabled-text: #ADB5BD; }

Usage

Body 텍스트는 15px 미만으로 축소하지 않습니다. 모바일 Landscape(844×390) 기준 최소 크기가 가독성 하한선입니다.

✓ Do

Heading과 Body의 굵기 차이(Bold vs Medium)로 위계를 만듭니다.

✕ Don't

같은 굵기에서 크기만 줄여 위계를 표현하지 않습니다 — 대비가 약해집니다.

Patterns / 02

Accessibility

PC, 모바일, 게임패드 등 다양한 입력 방식을 모두 고려한 접근성 기준입니다.

🎨 Contrast

텍스트 대비 최소 4.5:1, 큰 텍스트(18px+) 3:1 이상을 유지합니다.

👆 Touch Area

모든 인터랙티브 요소는 최소 44×44px의 터치 영역을 확보합니다.

⌨️ Keyboard Focus

Tab 순서는 시각적 흐름과 일치하며, 포커스는 항상 명확히 표시됩니다.

🔵 Focus Ring

Primary 4px Ring을 모든 포커스 가능한 요소에 일관되게 적용합니다.

🎮 Gamepad

D-Pad/Stick 내비게이션 시 포커스 순서는 Grid 인덱스를 따릅니다.

🔊 Screen Reader

아이콘 전용 버튼에는 반드시 접근성 레이블을 지정합니다.

Animation 적용

UMG Animation 트랙은 머티리얼 인스턴스별 스칼라 파라미터를 직접 키프레임할 수 없습니다. 아이콘 스케일 등 위젯 트랜스폼은 Animation 트랙으로, 머티리얼 파라미터(Glow, Pulse 등)는 Blueprint의 Set Scalar Parameter Value로 제어합니다.
